# PySpark interview

## Uruchomienie w MyBinder

Repozytorium musi byc publiczne i opublikowane na GitHubie. Po wypchnieciu
zmian na galaz `master` otworz:

https://mybinder.org/v2/gh/lkulwick/f5b-interview/master?urlpath=lab/tree/pyspark/Pyspark_fifty5blue_Interview.ipynb

Jesli domyslna galaz ma inna nazwe, zastap `master` jej nazwa w adresie.
Pierwsze uruchomienie po zmianie repozytorium moze zajac kilka minut, poniewaz
Binder buduje obraz. Warto uruchomic link przed rozmowa i wybrac w notebooku
**Run > Run All Cells**, aby sprawdzic srodowisko.

Spark dziala lokalnie w sesji Binder, bez osobnego klastra. Sesje sa tymczasowe:
przed ich zakonczeniem pobierz rozwiazany notebook, wybierajac **Download** z
menu kontekstowego pliku w przegladarce plikow JupyterLab.
Zadania w publicznym repozytorium sa widoczne dla wszystkich; nie umieszczaj
w nim danych wrazliwych ani sekretow.
